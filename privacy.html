SNS Saibai — Privacy Policy

Last updated: 2026-10-15

SNS Saibai is a personal tool used only by its owner (ai.atelier.sora, contact: ai.atelier.sora+instagram@gmail.com) to publish the owner's own illustrations to the owner's own social media accounts and to read the reactions to those posts. It is not offered to other users.

What data the tool accesses

  • The owner's own account only: profile information (account name, follower count), the owner's own posts/pins and boards, and the reaction metrics of those posts/pins (e.g. likes, saves, impressions, clicks), through the official APIs of Pinterest, Instagram and Bluesky, with the owner's authorization (OAuth).
  • The tool does not access, collect or store data about other users.

How the data is used

  • To create posts/pins of the owner's illustrations after the owner approves each one.
  • To show the owner a dashboard of how the owner's posts perform.

Where the data is stored

  • Only on the owner's own computer (a local database). It is not sold, shared or transferred to anyone.
  • Access tokens are stored locally and are never shown or sent anywhere except to the official API of each service.

Retention and deletion

  • The owner can delete the local data and revoke the tool's access at any time from each service's settings (e.g. Pinterest: Settings → Security and logins → Apps; Instagram: Settings → Apps and websites).

Contact

  • ai.atelier.sora+instagram@gmail.com

SNS栽培 — プライバシーポリシー

最終更新: 2026-10-15

SNS栽培 は、作者（黒音 小鈴／ai.atelier.sora・連絡先 ai.atelier.sora+instagram@gmail.com）が、自分の作ったイラストを自分の SNS アカウントに投稿し、その反応を見るためだけに使う個人用のツールです。ほかの人には提供していません。

扱うデータ

  • 作者自身のアカウントのものだけ: プロフィール（アカウント名・フォロワー数）、作者自身の投稿・ピン・ボード、その反応（いいね・保存・表示・クリックなど）。Pinterest・Instagram・Bluesky の公式 API を、作者の許可（OAuth）のもとで使います
  • ほかの利用者のデータは、読み取り・収集・保存しません

使いみち

  • 作者が 1 件ずつ承認したイラストを投稿・ピンにするため
  • 作者が自分の投稿の反応を見るため（ダッシュボード）

保存する場所

  • 作者のパソコンの中（ローカルのデータベース）だけ。販売・共有・第三者への提供はしません
  • アクセストークンはパソコンの中に保存し、各サービスの公式 API に送る以外には使いません

削除

  • 作者はいつでも、パソコンのデータを消し、各サービスの設定からツールの許可を取り消せます
